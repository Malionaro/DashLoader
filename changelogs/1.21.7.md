# DashLoader 5.1.0-beta.9.1+1.21.7 (Unofficial Continuation)  Changes since beta.9:  - Fixed `Failed caching` crash caused by unregistered `StitcherAccessor` - Tolerant texture stitching: stitch parameters (max size, mip level) are validated before cache reuse, stale packing re-stitches vanilla instead of corrupting the atlas - Resource pack hash now includes pack title and description, so updated packs rebuild once instead of falling back every boot - Duplicate atlases and sprites keep the first result instead of being dropped from the cache - Missing default font in cache no longer crashes loading, falls back to vanilla font loading - `UNSAFE_MIPMAP_GENERATION` auto-disables on Quilt (avoids a MixinExtras crash)  Requires Fabric Loader 0.19.5 or newer and Java 21.
