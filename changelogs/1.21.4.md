# DashLoader 5.1.0-beta.9+1.21.4 (Unofficial Continuation)

First release of the community continuation for 1.21.4 (based on upstream `5.1.0-beta.8`).

## Port & fixes vs upstream

- Verified 1.21.4 port with updated mappings, Loom and Fabric Loader (≥ 0.19.5)
- **#121**: modded multipart model parts (e.g. Refined Storage cables) no longer abort the whole save — they are skipped with a warning and loaded vanilla
- **#85**: uncacheable (modded) sprites are skipped instead of failing the cache — safe, vanilla loading is used for them
- **#61 / #32**: uncacheable fonts no longer abort the save (skipped with a warning)
- Merged upstream translations: Russian (`ru_ru`), pre-reform Russian (`rpr`), Tatar (`tt_ru`), Ukrainian (`uk_ua`), Brazilian Portuguese (`pt_br`)
- Upstream null-guard (`#112`): game starts even if the cache is unavailable

Requires Fabric Loader ≥ 0.19.5 and Java 21.
