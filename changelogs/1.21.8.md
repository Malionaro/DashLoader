# DashLoader 5.1.0+1.21.8 (Unofficial Continuation)

First stable release of the community continuation for 1.21.8 (based on upstream `5.1.0-beta.8`).

## What is this?

The original project stopped at 1.21.4. This continuation keeps DashLoader alive: it ports the mod to newer versions and fixes long-standing cache failures. Licensed LGPL-3.0-only, full credit to AlphaQ and all contributors.

## Port notes

- Full 1.21.8 port with updated mappings and mixins

## Fixes vs upstream beta.8

- **#121**: modded multipart model parts are skipped with a warning instead of aborting the save
- **#85**: uncacheable (modded) sprites are skipped instead of failing the cache
- **#61 / #32**: uncacheable fonts are skipped instead of aborting the save
- Missing default font in cache no longer crashes loading — falls back to vanilla font loading
- `UNSAFE_MIPMAP_GENERATION` auto-disables on Quilt (avoids a MixinExtras crash)
- Merged upstream translations: `ru_ru`, `rpr`, `tt_ru`, `uk_ua`, `pt_br`
- Upstream null-guard (`#112`)

Note: GPU-side caches (atlases, shaders) are not cached on 1.21.5+ — Mojang removed the hooks. CPU-side caching still applies.

Requires Fabric Loader ≥ 0.19.5 and Java 21. Quilt supported.
