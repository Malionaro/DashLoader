# DashLoader 5.1.0+1.21.4 (Unofficial Continuation)

First stable release of the community continuation for 1.21.4 (based on upstream `5.1.0-beta.8`).

## What is this?

The original project stopped at 1.21.4. This continuation keeps DashLoader alive: it ports the mod to newer versions and fixes long-standing cache failures. Licensed LGPL-3.0-only, full credit to AlphaQ and all contributors.

## Fixes vs upstream beta.8

- **#121**: modded multipart model parts (e.g. Refined Storage cables) no longer abort the whole save — skipped with a warning, loaded vanilla
- **#85**: uncacheable (modded) sprites are skipped instead of failing the cache
- **#61 / #32**: uncacheable fonts are skipped instead of aborting the save
- Missing default font in cache no longer crashes loading — falls back to vanilla font loading
- `UNSAFE_MIPMAP_GENERATION` auto-disables on Quilt (avoids a MixinExtras crash); Quilt tested working
- Merged upstream translations: Russian (`ru_ru`), pre-reform Russian (`rpr`), Tatar (`tt_ru`), Ukrainian (`uk_ua`), Brazilian Portuguese (`pt_br`)
- Upstream null-guard (`#112`): game starts even if the cache is unavailable

Requires Fabric Loader ≥ 0.19.5 and Java 21. Quilt supported (tested on 26.2).
