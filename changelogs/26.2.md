# DashLoader 5.1.0-beta.9.1+26.2 (Unofficial Continuation) - BETA

Beta continuation release for 26.2 (based on upstream `5.1.0-beta.8`, Mojang mappings).

## Port & fixes vs upstream

- Full 26.2 port: Mojang mappings, `ReloadState` model hooks, `Component` splash texts, per-font save resilience
- Missing default font in cache no longer crashes loading - falls back to vanilla font loading
- **#85**: uncacheable (modded) sprites are skipped instead of failing the cache
- `UNSAFE_MIPMAP_GENERATION` auto-disables on Quilt (avoids a MixinExtras crash) - Quilt tested working
- Tested with Sodium + Iris: SAVE (32366 models) and LOAD (286ms) verified
- Merged upstream translations: `ru_ru`, `rpr`, `tt_ru`, `uk_ua`, `pt_br`
- Upstream null-guard (`#112`)

Beta status: Fabric toast rendering pending final confirmation. Please report issues with `latest.log`.

Requires Fabric Loader ≥ 0.19.5 and Java 25. Quilt supported.

## Changes since beta.9

- Tolerant texture stitching: stitch parameters (max size, mip level, anisotropy) are validated before cache reuse; stale packing re-stitches vanilla instead of corrupting the atlas
- Resource pack hash now includes pack title and description, so updated packs rebuild once instead of falling back every boot
- Duplicate atlases/sprites keep the first result instead of being dropped from the cache
- Toast hardened (never-null visibility, null-safe progress text)
- Missing default font in cache no longer crashes loading - falls back to vanilla font loading
- `UNSAFE_MIPMAP_GENERATION` auto-disables on Quilt (avoids a MixinExtras crash)
- Fixed `Failed caching` crash from unregistered `StitcherAccessor`
