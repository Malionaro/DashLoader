# DashLoader 5.1.0-beta.8+26.1.2 (Unofficial Continuation) — BETA

Beta continuation release for 26.1.2 (based on upstream `5.1.0-beta.8`, Mojang mappings).

## Port & fixes vs upstream

- Full 26.1.2 port: Mojang mappings, non-remapped Loom setup, `BlockStateModel` pipeline
- Bitmap fonts use the native 26.1 shape (no reflection); per-font save resilience
- **#85**: uncacheable (modded) sprites are skipped instead of failing the cache
- Merged upstream translations: `ru_ru`, `rpr`, `tt_ru`, `uk_ua`, `pt_br`
- Upstream null-guard (`#112`)

Beta status: startup splash skip and cache LOAD need testing. Please report issues with `latest.log`.

Requires Fabric Loader ≥ 0.19.5 and Java 25.
