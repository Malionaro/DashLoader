# DashLoader 5.1.0-beta.9+26.1 (Unofficial Continuation) — BETA

Beta continuation release for 26.1 (based on upstream `5.1.0-beta.8`, Mojang mappings).

## Port & fixes vs upstream

- Full 26.1 port: Mojang mappings, non-remapped Loom setup, `BlockStateModel` pipeline
- Bitmap fonts use the native 26.1 shape (no reflection); uncacheable fonts are skipped
- Missing default font in cache no longer crashes loading — falls back to vanilla font loading
- **#85**: uncacheable (modded) sprites are skipped instead of failing the cache
- `UNSAFE_MIPMAP_GENERATION` auto-disables on Quilt (avoids a MixinExtras crash)
- Merged upstream translations: `ru_ru`, `rpr`, `tt_ru`, `uk_ua`, `pt_br`
- Upstream null-guard (`#112`)

Beta status: font SAVE and cache LOAD need final verification. Please report issues with `latest.log`.

Requires Fabric Loader ≥ 0.19.5 and Java 25. Quilt supported.
