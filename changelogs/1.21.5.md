# DashLoader 5.1.0-beta.9+1.21.5 (Unofficial Continuation)

Continuation release for 1.21.5 (based on upstream `5.1.0-beta.8`).

## Port & fixes vs upstream

- Full 1.21.5 port: `BlockStateModel`/`BlockModelPart` model caching, rewritten toast rendering, updated mixins
- **#121**: modded multipart model parts are skipped with a warning instead of aborting the save
- **#85**: uncacheable (modded) sprites are skipped instead of failing the cache
- **#61 / #32**: uncacheable fonts are skipped instead of aborting the save
- Merged upstream translations: `ru_ru`, `rpr`, `tt_ru`, `uk_ua`, `pt_br`
- Upstream null-guard (`#112`)

Note: GPU-side caches (atlases, shaders) are not cached on 1.21.5+ — Mojang removed the hooks. CPU-side caching still applies.

Requires Fabric Loader ≥ 0.19.5 and Java 21.
